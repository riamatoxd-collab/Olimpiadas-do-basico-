# Venture All Star — Cozinha: banco de questões

## Fonte e método
O banco inicial contém **55 questões baseadas no Book Olimpíadas de Básico — Venture.docx**, enviado pelo usuário. Cada item do banco guarda a página e o número da questão de origem.

As perguntas foram adaptadas para o formato de múltipla escolha. O enunciado e a resposta correta se baseiam no book; as alternativas incorretas (distratores) foram elaboradas para o jogo e **não são alternativas transcritas do book**. O banco não deve ser descrito como uma transcrição literal integral do documento.

## UHC de carnes vermelhas
O book enviado é a fonte adotada para este banco:
- Questão 13, página 1: carnes vermelhas a **79°C**; carnes brancas a 85°C.
- Questão 14, página 1: tempo de vida das carnes vermelhas na UHC de **10 minutos**.

Um material complementar anterior tinha valores diferentes para esse parâmetro. O All Star segue o book para este ponto.

## Regras da experiência
- Treinamento: feedback imediato, explicação e fonte/página/questão de origem.
- Competição: até 10 perguntas sorteadas, sem revelar gabarito ou fonte durante a prova.
- Revisão final: mostra respostas, gabarito e origem no book.
- Histórico e melhor nota são separados do XP oficial. O All Star não concede nem desconta XP.
- A meta sugerida de 80% é apenas uma regra do simulado Venture; não é certificação oficial.

## Limitações
- O banco cobre apenas as perguntas selecionadas das áreas de cozinha; não representa as 200 questões do book inteiro.
- Os distratores foram escritos para o quiz e devem ser revisados antes de usar a experiência como instrumento de avaliação formal.
- A aplicação não certifica o usuário nem representa uma classificação oficial da competição All Star.
