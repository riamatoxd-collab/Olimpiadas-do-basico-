3. Backup técnico privado

Confidencial: o backup pode conter senhas em texto simples e informações pessoais. Não envie o arquivo para o GitHub, para este chat ou para outros colaboradores.

Este botão apenas cria um arquivo local para download. Não modifica os dados do jogo.

4. O que enviar como resultado

Informe apenas os quatro totais acima: nomes encontrados, contas ativas, contas ausentes e registros para revisão. Não é necessário enviar JSON nem nomes de colaboradores.

A conferência por si só não restaura contas e não habilita sincronização. Uma etapa posterior será necessária após validar as diferenças.
